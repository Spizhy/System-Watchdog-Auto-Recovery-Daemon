# System-Watchdog-Auto-Recovery-Daemon
Сфера: Системное программирование / DevOps-утилиты Суть автоматизации: Легковесный системный демон, который решает проблему зависших процессов и утечек памяти на серверах. Он считывает системные метрики (через /proc в Linux или Windows API), находит процессы, которые превышают заданные лимиты потребления CPU или RAM в течение определенного времени
